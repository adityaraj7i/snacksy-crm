# Snacksy Cafe Android app

Native Android WebView shell for the live Snacksy CRM at `https://snacksycrm-nine.vercel.app/`.

- Package: `com.snacksy.cafe`
- Minimum Android: 7.0 (API 24)
- File chooser support for menu photos
- Excel/CSV download support
- Android back-button navigation
- HTTPS-only traffic and external-link isolation

Build a test APK with `gradlew.bat assembleDebug`. The output is written to `app/build/outputs/apk/debug/app-debug.apk`.
